# HireSense AI

### Semantic Resume Intelligence Platform

HireSense AI is an NLP-powered resume intelligence platform that performs semantic candidate-job matching, skill gap analysis, and AI-driven recruiter insights using transformer embeddings.

## Live Demo
https://hiresense-ai-y4hxzmkz7kl7phxs53crkg.streamlit.app/

## Features

- Semantic Resume Matching
- AI-Powered Candidate Analysis
- Skill Gap Detection
- Resume Parsing from PDF
- NLP Text Preprocessing
- Recruiter Insight Generation
- Interactive Dashboard
- Match Score Visualization
- Explainable AI Matching
